# Ten-Year Channel Ranks

Live interactive screener for the Fixed 2,500-Trading-Day Standard Deviation Channel across stocks over $50bn market cap and Atlas UCITS ETFs.

- **Live site:** https://soylee22.github.io/sd-channel-scanner/
- **Data feed:** Updated every weekday at 22:15 UTC by the `SD Channel Daily Scan` GitHub Action in `soylee22/atlas-stock-screener` (`sd_channel/data.json`).
