Method: Python port of the Pine indicator "Fixed 2500-Trading-Day Std Dev Channel". Window is every daily bar within 3,624 calendar days of the last close (about 2,493 bars). Least-squares line of close on time, residual SD with n - 1. SD position = (close - line value at last bar) / SD.
The fit is linear in price. Compounding names such as NVDA follow a curve, which widens the SD and pulls their position towards zero. Rows with Pearson R under 0.7 are hidden by default and greyed when shown.
